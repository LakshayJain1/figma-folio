# figma-folio

Figma-canvas themed product designer portfolio.

## Folder structure

```
figma-folio/
├── content-template.md   ← fill this in first
├── src/
│   ├── cases/            ← one file per case study once we build
│   └── assets/
│       └── images/       ← avatar.png, case-XX-cover.png, etc.
└── public/               ← built output
```

## Next step
Fill in `content-template.md` with your info, then run `/build` to generate the site.
